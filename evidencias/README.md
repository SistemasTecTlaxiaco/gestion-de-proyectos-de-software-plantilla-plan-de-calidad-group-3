# EVIDENCIAS DEL PLAN DE CALIDAD

## Sistema de Gestión Comercial para Artesanías de Olla de Barro y Canastas Tejidas a Mano

Esta carpeta contiene las evidencias relacionadas con la aplicación y seguimiento del Plan de Calidad del proyecto.

## Evidencias consideradas

| No. | Evidencia             | Descripción                                                              |
| --: | --------------------- | ------------------------------------------------------------------------ |
|   1 | Historias de Usuario  | Evidencias de las historias de usuario y sus criterios de aceptación     |
|   2 | Auditoría mediante IA | Evidencias de las revisiones realizadas mediante Inteligencia Artificial |
|   3 | Tablero eduScrum      | Capturas del seguimiento de las actividades                              |
|   4 | Pruebas               | Evidencias de las pruebas realizadas al sistema                          |
|   5 | Métricas de Calidad   | Resultados de las métricas establecidas                                  |
|   6 | Gestión de Defectos   | Registro y seguimiento de errores encontrados                            |
|   7 | Costo de la Calidad   | Evidencias de los cálculos de prevención y corrección                    |
|   8 | GitHub                | Evidencias del control de versiones y organización del proyecto          |

---

## Organización

Las evidencias se irán agregando conforme avance el desarrollo del proyecto y se realicen las actividades correspondientes.

Cada evidencia deberá estar relacionada con algún apartado del **Plan de Calidad**.
