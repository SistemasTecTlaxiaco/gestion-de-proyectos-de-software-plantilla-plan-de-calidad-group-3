## 2. Objetivo

Registrar y analizar el costo de calidad relacionado con cada historia de usuario del proyecto, considerando las horas destinadas a la prevención de errores y las horas necesarias para su corrección.

Este registro permite identificar la relación entre las actividades de prevención y corrección dentro del proyecto.

---

## 3. Costo de calidad

El costo de calidad se analiza mediante dos elementos principales:

* **Horas de prevención:** tiempo utilizado para evitar errores antes de que ocurran.
* **Horas de corrección:** tiempo utilizado para solucionar errores encontrados durante el desarrollo o las pruebas.

---

## 4. Fórmulas utilizadas

### Índice de prevención/corrección

**Índice = Horas de prevención ÷ Horas de corrección**

Este indicador permite observar la relación entre el tiempo destinado a prevenir errores y el tiempo destinado a corregirlos.

### Ahorro potencial

**Ahorro potencial = Horas de corrección − Horas de prevención**

Este valor representa la diferencia entre las horas destinadas a corrección y las horas destinadas a prevención.
