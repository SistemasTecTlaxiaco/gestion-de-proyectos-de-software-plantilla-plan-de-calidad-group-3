## Descripción del proyecto

El proyecto consiste en desarrollar un **Sistema de Gestión Comercial para Artesanías de Olla de Barro y Canastas Tejidas a Mano**, orientado a apoyar a los artesanos de la Región Mixteca.

El sistema busca facilitar el registro y consulta de productos, el control de inventario, el registro de ventas y la generación de reportes relacionados con la actividad comercial.

Además, se consideran las condiciones del contexto regional, como la conectividad limitada, el uso de equipos de bajos recursos y los diferentes niveles de conocimiento tecnológico.

---

## Objetivo del Plan de Calidad

Establecer los criterios, métricas, actividades y responsabilidades necesarias para verificar y mantener la calidad del sistema durante las diferentes etapas de su desarrollo.

## Modelos y herramientas consideradas

### CMMI

Se consideran prácticas relacionadas con:

* Gestión de requisitos.
* Planeación del proyecto.
* Gestión de configuración.
* Medición y análisis.
* Verificación.
* Validación.
* Gestión de riesgos.

### MoProSoft

Se consideran procesos relacionados con:

* Dirección.
* Gestión.
* Operación.
* Administración de proyectos.
* Desarrollo y mantenimiento.

### eduScrum

El flujo de trabajo utilizado para organizar las actividades es:

**Tareas/Propuestas → Revisión con IA → Aprobado por el equipo → En proceso → Terminada**

También se considera la columna **Descartadas** para las propuestas que no sean seleccionadas.

### Inteligencia Artificial

La IA se utiliza como herramienta de apoyo para:

* Revisar historias de usuario.
* Revisar criterios de aceptación.
* Detectar posibles riesgos.
* Revisar métricas.
* Proponer mejoras.

Las decisiones finales son tomadas por el equipo.
