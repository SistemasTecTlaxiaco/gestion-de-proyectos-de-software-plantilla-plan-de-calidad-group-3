## Descripción

El presente repositorio contiene el Plan de Calidad del proyecto
"Sistema de Gestión Comercial para Artesanías de Olla de Barro y
Canastas Tejidas a Mano", desarrollado para la asignatura Gestión de
Proyectos de Software.

El Plan de Calidad establece los criterios, métricas, pruebas,
responsabilidades y actividades necesarias para verificar la calidad
del proyecto.
